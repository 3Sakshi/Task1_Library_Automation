# Task1_Library_Automation
A Python-based Library Automation Tool developed as part of the Skyrovix Python Development Internship.

## 📌 Project Overview
The Library Automation Tool is a simple command-line application designed to manage library books efficiently.

It allows users to add, view, search, issue, return, and delete books. The project also includes input validation, error handling, data storage, and automated testing.

## 🚀 Features
- Add new books
- View all books
- Search books by title or author
- Issue books
- Return books
- Delete books
- Input validation
- Error handling
- Persistent book data storage
- Automated testing with pytest

## 🛠️ Technologies Used
- Python
- JSON
- Pytest

```text

```
The application provides a menu with options to manage library books.
